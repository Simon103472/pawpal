## Running locally

The project lives in XAMPP's web root (`C:\xampp\htdocs\pawpal`), so Apache serves it without extra configuration.

1. Open the XAMPP Control Panel and start **Apache** (and **MySQL** if needed).
2. Browse to <http://localhost/pawpal/>.

Until an `index.php` or `index.html` exists, that URL shows an empty directory listing.
